## Start with the incoming feed

NMEA 0183 uses sentences. NMEA 2000 uses messages identified by PGNs. Wi-Fi output depends on the gateway software. Read the manual for your model to see whether it converts messages to sentences or exposes a raw feed.

## Compare output using one sensor

Start with a reading available in both modes. Then check each reading you need on board. A successful speed test does not verify engine data.
