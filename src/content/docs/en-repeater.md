## Identify your instrument output

Find the model of the gateway or server on your boat. Check its manual for the output format, transport, address and port. A gateway connected to an NMEA 2000 backbone may expose a different data format over Wi-Fi. Identify the output before choosing a profile in PyNav.

## Start with a single reading

Join the boat network on your iPhone or iPad. Set up the PyNav profile that matches the gateway output. Add one reading you already have on a boat instrument, such as speed or wind. Compare the units and values. Check that the source reading changes before troubleshooting a static value.

## Diagnose an empty gauge

If every gauge is empty, check the network, address, port and transport first. If only one gauge is empty, check that the sensor provides that reading and that the gateway forwards it in the selected format. Compare like for like, for example speed over ground with speed over ground.

## Download PyNav

Install PyNav from the App Store and start with a reading you can compare against an onboard display. Use the Wi-Fi guide below to check the gateway format.
